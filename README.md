# Café Ordering System

Cloud App Development · Exercise 1: modelling a café menu and orders with TypeScript types.

South East Technological University (SETU)

## What it covers

- **Types** (`src/menuTypes.d.ts`): menu items with courses, prices and nutrition (calories and allergens), combo deals, order lines, kitchen tickets and allergy cards.
- **Logic** (`src/cafe.ts`): builds the menu, a lunch combo and an order, and uses typed functions to describe items, total up order lines and the order, filter the menu, and find the cheapest or first matching item.

## Running it

```bash
npm install
npx ts-node src/cafe.ts
```

## Tools

TypeScript · Node.js
